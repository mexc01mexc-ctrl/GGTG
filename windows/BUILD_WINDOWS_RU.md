# Сборка GGTG для Windows (.exe) через GitHub Actions

Сборка Windows `.exe` выполняется полностью в облаке GitHub Actions без необходимости иметь физический Windows-компьютер.

---

## 1. Запуск сборки свежего .exe

1. Откройте вкладку **Actions** в репозитории:  
   `https://github.com/<ваш-логин>/GGTG/actions`
2. В левой колонке выберите воркфлоу **`Build Windows EXE`**.
3. Справа нажмите **«Run workflow»** → ветка `main` → зелёная кнопка **«Run workflow»**.
4. По окончании сборки кликните на завершённый запуск и скачайте архив **`GGTG-Windows-x64`** из раздела **Artifacts** внизу страницы.
5. Внутри архива находится готовый исполняемый файл **`Telegram.exe` / `GGTG.exe`**.

---

## 2. Отправка обновлений с Mac на GitHub

После внесения любых доработок в код на Маке, отправка изменений в облако выполняется стандартно:

```bash
git add .
git commit -m "Описание обновлений"
git push origin main
```

Все новые изменения сразу попадут в следующую сборку `Build Windows EXE`.

---

## 3. Перенос проекта на другой аккаунт GitHub (если исчерпан лимит минут)

Если бесплатные 2000 минут GitHub Actions в текущем месяце закончились:

1. **Создайте новый приватный репозиторий:**
   * Зайдите на GitHub под новым аккаунтом: `github.com/new`
   * Назовите репозиторий `GGTG`, выберите **Private**, галочки инициализации не ставьте.
2. **Добавьте SSH-ключ вашего Mac:**
   * Скопируйте публичный ключ Мака (команда в терминале: `cat ~/.ssh/id_ed25519.pub`).
   * Вставьте его в настройки нового GitHub: `Settings -> SSH and GPG keys -> New SSH key`.
3. **Переключите адрес репозитория на Маке и отправьте код:**
   ```bash
   git remote set-url origin git@github.com:<НОВЫЙ-ЛОГИН>/GGTG.git
   git push -u origin main
   ```
4. **Готово:**
   На новом аккаунте сразу появятся все воркфлоу и код, и вы сможете запускать сборки с новым запасом в 2000 минут.

---

## 4. Папка с аккаунтами (tdata) для Windows

* На Windows рабочая папка с аккаунтами `tdata` должна находиться **в той же папке**, где лежит сам файл `GGTG.exe`.
* Перед заменой старого `.exe` на новый всегда делайте резервную копию папки `tdata`.

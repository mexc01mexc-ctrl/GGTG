# GGTG для Windows: пересборка exe

Библиотеки (`D:\TBuild\Libraries`, `D:\TBuild\ThirdParty`) пересобирать не нужно.
Меняются только исходники, пересборка exe: 20–60 минут.

## Что нового в этой версии

**ИИ теперь только облачный, как «второй мозг».** Локальные модели и движок убраны
(освобождается до 12 ГБ). Полное описание и пошаговая настройка ключей: `docs/ggtg-ai-cloud.md`.

- **Один экран «ИИ»** с пронумерованными шагами: ключи, о бизнесе и цель, материалы,
  обучение на чатах, лента ответов.
- **Ключи:** Gemini, Groq, OpenRouter, GitHub Models, NVIDIA NIM; любое число ключей,
  провайдер определяется сам, при лимите ИИ сам берёт следующий. Имена людей в
  рассылке скрываются.
- **Материалы:** PDF, Word, txt, картинки, ссылки на сайты, YouTube; режутся на куски и
  подтягиваются в каждый ответ.
- **Обучение на ваших чатах** (в «Процессах», можно остановить и продолжить): стиль,
  вопросы, возражения, ваши ответы и чем закончился диалог.
- **Лента ответов с одобрением:** этап (вопрос, возражение, интерес, отказ), кнопки
  «Отправить / Изменить / Пропустить», правки учат ИИ, горячий лид помечается.
- **Спросить свой второй мозг** (чат-агент), утренняя сводка, проверка качества.
- **Рабочие списки:** списки чатов (ПКМ по чату → «В список GGTG», раздел «Списки чатов»,
  «Написать всем» по списку с фото, подписью и паузами); разбивка базы по языкам имён;
  сортировка базы по имени и @username; в списке базы окно остаётся открытым при смене
  аккаунта, отправленные внизу, ошибки отправки помечаются, статус обновляется после
  ручной отправки.
- Форма рассылки SMS: шаги пронумерованы и обведены рамками.
- **Пока идёт процесс (рассылка, сбор, обучение и т. д.), компьютер не засыпает, экран не гаснет и не блокируется по бездействию.** Когда процессов нет, всё как обычно.
- **Лента ответов теперь и в «Главной»** (сверху): кто ответил, что предлагает ИИ, «Отправить / Изменить / Пропустить».
- **Кнопка разделов всегда на виду:** в узком окне она открывает список разделов, а не пропадает.
- **Журнал аккаунта в рассылке** (клик по строке аккаунта) и **ключи ИИ по сервисам**.
- **Обучение на чатах:** аккаунты по папкам, как в рассылке.

Исправлены ошибки сборки Windows: `ggtg_squidward_session.cpp` (C2664), `sms_campaign_widgets.h` (QPolygonF, C2440), `process_manager.cpp` (C1083). Весь изменённый код теперь проверен на Mac против Qt 5.15.19 — той же версии, что на Windows (`ggtg-tests/check_windows_qt5.sh`). Если сборка всё же остановится, пришли первые строки с `error`.

## Важно перед началом

- **Аккаунты лежат в папке `tdata` рядом с `.exe`** (`D:\TBuild\tdesktop\out\Release\tdata`).
  Сделай её копию до обновления (шаг 2). Новая версия читает старые данные,
  а старая новые прочитать может не суметь.
- **Без своего прокси аккаунт не подключается.** После обновления аккаунты без
  прокси будут со статусом «Нет прокси», пока его не задать (Менеджер аккаунтов →
  «Массовое действие...» → «Заменить прокси»).
- Одну и ту же копию `tdata` нельзя запускать на двух компьютерах одновременно:
  Telegram разорвёт сессию.

## Шаг 1. Перенести архив

Скопируй `GGTG-windows-src.zip` (на Маке: `GGTG/APP/`, собирается скриптом `desktop/nicegram-desktop/Telegram/build/ggtg/make_windows_zip.sh`) в `D:\`.
Проверь, что размер файла около 94 МБ (93 882 140 байт) и дата свежая:

```powershell
Get-Item D:\GGTG-windows-src.zip | Select-Object Length, LastWriteTime
```

## Шаг 2. Копия аккаунтов

Закрой приложение. В PowerShell:

```powershell
Copy-Item D:\TBuild\tdesktop\out\Release\tdata D:\tdata-backup -Recurse
```

## Шаг 3. Заменить исходники (папка `out` сохраняется)

```powershell
Remove-Item D:\TBuild\unzip -Recurse -Force -ErrorAction SilentlyContinue
Expand-Archive -Path D:\GGTG-windows-src.zip -DestinationPath D:\TBuild\unzip
robocopy D:\TBuild\unzip\nicegram-desktop D:\TBuild\tdesktop /E /IS /IT
Remove-Item D:\TBuild\unzip -Recurse -Force
dir D:\TBuild\tdesktop\Telegram\SourceFiles\settings\ggtg_chat_lists_ui.h
```

- `robocopy` вернёт код 1–3: это нормально. Ключи `/IS /IT` обязательны: без них
  файлы с тем же размером и датой не заменяются и остаётся старый код.
- Последняя команда должна показать файл `ggtg_chat_lists_ui.h`. Если пишет «File Not
  Found», исходники не обновились: повтори шаг 3.

## Шаг 3а. Убрать старый локальный ИИ (один раз)

Локальных моделей в этой версии нет, они были на 12 ГБ. Если ИИ ставился раньше:

```powershell
Remove-Item D:\TBuild\tdesktop\out\Release\tdata\ggtg_db\ai -Recurse -Force -ErrorAction SilentlyContinue
```

Настройки и ключи это не трогает (если папки нет, команда ничего не сделает).

## Шаг 4. Терминал сборки (cmd, не PowerShell)

Win+R, `cmd`, Enter:

```bat
"D:\VS2026\VC\Auxiliary\Build\vcvars64.bat" -vcvars_ver=14.44
```

Все следующие шаги в этом же окне.

## Шаг 5. Конфигурация (обязательна: новые файлы)

```bat
cd /d D:\TBuild\tdesktop\Telegram
configure.bat x64 -D TDESKTOP_API_ID=2040 -D TDESKTOP_API_HASH=b18441a1ff607e10a989891a5462e627
```

В конце должно быть `Generating done`.

## Шаг 6. Сборка

```bat
cd /d D:\TBuild\tdesktop\out
cmake --build . --config Release --target Telegram
```

Строк `error` в конце быть не должно. Результат:
`D:\TBuild\tdesktop\out\Release\GGTG.exe`.

## Шаг 7. Запуск

Запускай `D:\TBuild\tdesktop\out\Release\GGTG.exe`. Папка `tdata` лежит рядом:
аккаунты остаются на месте. При первом запуске папка данных программы
`tdata\nicegram_bulk_db` сама переименуется в `tdata\ggtg_db`, ничего не теряется.
Можно создать ярлык на `GGTG.exe` на рабочем столе.

## Если ошибка

Пришли последние ~50 строк из cmd и номер шага. Аккаунты: закрой приложение, удали
`D:\TBuild\tdesktop\out\Release\tdata` и верни копию:

```powershell
Copy-Item D:\tdata-backup D:\TBuild\tdesktop\out\Release\tdata -Recurse
```

# Инструкция по разработке и сборке GGTG в GitHub Actions

Этот документ описывает рабочий процесс (workflow) разработки GGTG: как вносить изменения в код, как они автоматически попадают на сборку в GitHub Actions и как скачивать готовые файлы без нагрузки на ваш компьютер.

---

## 1. Архитектура рабочего процесса

* **На ноутбуке:** хранится только чистый исходный код репозитория (`~500 МБ`). Все тяжелые кэши компиляторов и промежуточные файлы удалены, освобождая 20–25 ГБ места на диске.
* **В облаке GitHub Actions:** при каждом `git push` три параллельных раннера (Linux, macOS Apple Silicon, Windows) собирают дистрибутивы с использованием компиляторных кэшей (`ccache`, `sccache`, Gradle build-cache).
* **Готовые файлы:** автоматически публикуются в разделе **Actions → Artifacts** репозитория:
  * `GGTG-Android` (`.apk`)
  * `GGTG-macOS-DMG` (`.dmg`)
  * `GGTG-Windows-x64` (`.zip` с `GGTG.exe`)

---

## 2. Пошаговая инструкция: как вносить изменения

### Шаг 1. Редактирование кода
Вы или AI-ассистент вносите правки в нужные файлы проекта:
* Для Android: в директории `android/Telegram-GGTG/`
* Для macOS и Windows: в директории `desktop/nicegram-desktop/` (исходный код Desktop общий для обеих ОС)

> [!IMPORTANT]
> **Правила разработки:**
> 1. Строго соблюдайте `docs/UI_STYLE_GUIDE.md`: никаких эмодзи в интерфейсе (только официальные векторные иконки Telegram).
> 2. Сохраняйте паритет между Desktop и Android.
> 3. Помечайте новые участки кода комментариями `// ggtg:` или `// ng:`.

### Шаг 2. Обновление индекса файлов (если добавлялись/удалялись файлы)
Если вы создали новый файл или удалили старый, выполните:
```bash
python3 tools/update_file_index.py
```

### Шаг 3. Фиксация изменений в Git
Проверьте измененные файлы и сделайте коммит:
```bash
git status
git add .
git commit -m "feat: краткое описание того, что изменили"
```

### Шаг 4. Отправка в GitHub (запуск автоматической сборки)
```bash
git push origin main
```
После выполнения команды GitHub Actions автоматически определит, какие платформы затронуты изменениями, и запустит сборку.

---

## 3. Где и как забирать готовые файлы

1. Перейдите на страницу репозитория:
   `https://github.com/mexc01mexc-ctrl/GGTG/actions`
2. Нажмите на верхний запуск воркфлоу с вашим комментарием коммита.
3. Внизу страницы в блоке **Artifacts** будут ссылки на скачивание:
   * **`GGTG-Android`** — распакуйте архив и получите свежий `.apk` файл.
   * **`GGTG-macOS-DMG`** — распакуйте архив и получите `.dmg` образ с готовым фоном и ссылкой на Applications.
   * **`GGTG-Windows-x64`** — распакуйте архив и получите `.zip` с готовым `GGTG.exe`.

---

## 4. Как работает фильтрация сборок (экономия времени)

Воркфлоу настроены так, чтобы не делать лишнюю работу:
* Если вы изменили **только Android** (`android/**`), запустится сборка **только Android APK** (macOS и Windows компилироваться не будут).
* Если вы изменили **только Desktop** (`desktop/**`), запустятся сборки **macOS DMG** и **Windows EXE**.
* Если нужно принудительно запустить сборку любой платформы без изменения кода, перейдите в **Actions → выберите нужный воркфлоу слева → нажмите кнопку Run workflow**.

---

## 5. Уведомления о статусе сборки

Все воркфлоу автоматически отправляют push-уведомления об успехе или ошибке сборки на канал:
`https://ntfy.sh/ggtg-ci-build-log-4e4b86e2`

Вы можете открыть эту ссылку в браузере или в мобильном приложении ntfy, чтобы сразу узнать, когда сборка завершилась и файл готов к загрузке.

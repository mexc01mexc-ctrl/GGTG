# Сквидвард: редизайн раздела

Дата: 2026-09-29
Код: `nicegram-desktop/Telegram/SourceFiles/window/ggtg_squidward.cpp` (+ новые файлы ниже)

## Зачем

Сейчас раздел зеркалит чат с @skvidvarde_bot: сырой текст каждого ответа и
все кнопки бота подряд. Это «каша»: непонятно, что главное и что делать
дальше. Цель — премиальный, понятный экран, который показывает только
нужные данные и только те действия, которые требуются от пользователя.

## Сценарии (подтверждены пользователем)

1. **Досье** — посмотреть информацию о человеке или группе.
2. **Группы человека → в базу групп.**
3. **Участники группы → в базу получателей** (в т.ч. закрытой группы).

Платные функции бота (кнопки с 💎, «Следить», «Подарки» и т.п.) не нужны и
нигде не показываются.

### Поле поиска
- Одно поле: `@username`, числовой ID, `t.me/name`, закрытая ссылка
  `t.me/c/<id>/<msg>` или инвайт. Enter или «→» — пробить.
- Человек это или группа, определяется по ответу бота (не по вводу).
- «Недавние»: последние 8 пробивов (текст + что это было), кликабельные;
  хранятся в `tdata/ggtg_squidward_recent.json`.
- Статус бота — точка в заголовке: подключается / подключён / ошибка.

### Досье человека (все поля, по согласованию)
Имя, @username, ID (всегда); период активности, сообщений/чатов, любимый
чат; реплаи %, медиа %, кружки, голосовые, разнообразие %; канал; «Искали»;
прошлые юзернеймы (строкой); история имён (свёрнута, раскрывается).
Главная кнопка: «👁 Собрать группы · N» (N — из первой страницы списка, если
ещё неизвестно — без числа).

### Досье группы
Название, @username/ссылка, ID; место в топе («#17 851 из 756 778»); за
сутки: людей, сообщений, % медиа, кружки/голосовые; разнообразие %;
описание (свёрнуто, если длинное); «Топ за сутки» — 10 строк (свёрнуто).
Главная кнопка: «👥 Собрать участников · N».

### Блок сбора
- Во время сбора — полоска «стр. X из Y · найдено N» и «Стоп».
- «Стоп» сохраняет уже собранное как готовый результат.
- Итог: одна строка счётчиков, 5–8 первых названий, «Сохранить в базу» и
  «Копировать». После сохранения кнопка — «✓ В базе — открыть».
- Группы: каналы убираются (как сейчас, `SquidwardFilterAndShowGroups`),
  закрытые 🔒 сохраняются в базу вместе со ссылкой (`ScrapedGroupEntry::link`).
- Имена баз: группы — «Имя (@username)» человека; люди — «Название
  (@username)» группы (`Data::GroupBaseTitle`), для закрытой — название.
- Новый пробив во время сбора — подтверждение «Остановить сбор?».

### Исходный ответ бота
Свёрнутая ссылка внизу; раскрывает очищенный текст последнего ответа.
Нужна только для разбора проблем. Все ответы по-прежнему пишутся в ggtg.log.

## 🦑 из «Базы»
Раздел открывается поверх, пробив запускается сам (по @username или по
ссылке для закрытой группы). После досье сбор участников стартует
автоматически, по окончании результат **сохраняется в базу автоматически**,
итог — тостом. В самом разделе сбор всегда только по кнопке.

## Ошибки
- Бот не ответил за 30 с — строка «Бот не отвечает» + «Повторить».
- Страница не пришла — одна повторная попытка, потом остановка с сохранением
  собранного (результат доступен как обычно).
- Бот ответил «не найдено»/ограничение — показывается на месте досье.
- Ответ не удалось разобрать — показывается очищенный текст ответа вместо
  карточки (без пустых мест), кнопки сбора ищутся как обычно.

## Устройство кода

Разбить текущий `ggtg_squidward.cpp` (~1 300 строк) на три единицы:

1. **`window/ggtg_squidward_parse.{h,cpp}`** — чистые функции без UI:
   - `ParseUserCard(TextWithEntities) -> std::optional<SquidwardUserCard>`
   - `ParseGroupCard(TextWithEntities) -> std::optional<SquidwardGroupCard>`
   - `ParsePageInfo` (перенос), извлечение строк групп/людей (перенос
     `SquidwardExtractGroupEntries`, `SquidwardExtractUsernames`).
   - Нормализация «стилизованных» букв бота (`İD`, `ɪᴅ`, `ҡ`, `ɪ` и т.п.) перед
     поиском меток; числа берутся из жирных сущностей, ID — из ссылок.
   - Проверяется на текстах с присланных скриншотов (4 образца).
2. **`window/ggtg_squidward_session.{h,cpp}`** — работа с ботом:
   подключение, `lookup(text)`, `collect()`, `stop()`; поиск и нажатие
   кнопок бота, листание страниц, таймауты. Отдаёт события через rpl:
   `cardReceived`, `progress`, `finished`, `failed`.
3. **`window/ggtg_squidward.cpp`** — только экран: поле, недавние, карточки,
   блок сбора. `MakeSquidwardBox(controller, lookupGroup)` сохраняет
   сигнатуру; при непустом `lookupGroup` включается режим 🦑
   (автосбор + автосохранение).

Без изменений переиспользуются: `SquidwardFilterAndShowGroups` (логика
фильтра каналов, без показа окна), `SquidwardResolveMentionedUsers`,
`Data::SaveScrapedGroupEntries/Usernames`, `GroupBaseTitle`.

## Вне рамок
Платные функции бота, «Похожие группы», «Скачать всё/сообщения», слежение,
общие группы и прочие кнопки бота.

## Проверка
- Разбор: 4 образца со скриншотов дают ожидаемые поля.
- Вручную: пробив человека, группы, закрытой ссылки; сбор со «Стоп»;
  сохранение; 🦑 из базы (открытая и закрытая группа); бот не отвечает.
